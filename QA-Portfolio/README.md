# QA Portfolio | Prospectors Exploration Map

This portfolio documents practical software quality assurance and data-validation work performed while developing **Prospectors Exploration Map**, part of the American Exploration Maps (AEM) project.

## Areas of hands-on experience

- **Functional testing:** map-layer behavior, search results, state-specific navigation, and expected vs. actual outcomes.
- **Data validation:** geospatial source coverage, record counts, geometry handling, and dataset consistency.
- **API testing:** inspecting JSON responses, endpoint behavior, and tile-serving results.
- **Regression testing:** verifying that changes to one state or layer do not break others.
- **Defect triage:** identifying causes, documenting evidence, applying or coordinating fixes, and distinguishing verified results from assumptions.
- **Release discipline:** syntax/build checks, production vs. test status, and rollback safeguards.
